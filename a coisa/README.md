Projeto de Programação Orientada a Objetos

Projeto desenvolvido durante os estudos de Programação Orientada a Objetos (POO) em Java.

Sobre o projeto

O projeto reúne classes desenvolvidas para praticar conceitos fundamentais de orientação a objetos, como:

Classes e objetos
Atributos e métodos
Encapsulamento
Construtores
Métodos static
Sobrescrita de métodos
toString()
Relacionamento entre classes
Organização e documentação de código Java
Classes

Descanso

Responsável por representar o controle de descanso do estudante, considerando a quantidade de horas de descanso e o período informado.

RegistroTempoOnline

Permite registrar o tempo de estudo de uma disciplina e verificar se a meta de estudos foi atingida.

controlarDisciplina

Representa uma disciplina, armazenando informações como notas, horas cadastradas e situação acadêmica.

RegistroResumo

Permite registrar e consultar resumos relacionados aos estudos.
